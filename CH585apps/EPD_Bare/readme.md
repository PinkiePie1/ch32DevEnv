# 裸机EPD程序

裸机墨水屏驱动。
使用SPI0.

## 接线

SPI0接口：
```
SCK(CSL)默认在PA13
MOSI(SDA)默认在PA14
```
如需改动需要配置GPIO重映射。

其他端口：RES DC CS BUSY为通用GPIO，默认配置：
```
PA12 RES 输出
PA7 DC 输出
PA9 CS 输出
PA8 BUSY 输入
```

三线SPI时序是非标的，不能用硬件SPI，暂时不考虑实现。

## 使用

具体使用方式详见main.c中的主函数。

程序需要4.7k的数组于RAM中作为显存，最好为4字节对齐，
同样的，所有图片最好四字节对齐。尤其是需要调用FastImg函数的。

单片机上电初始化之后，需要初始化delay函数（即启动systick），如不想用systick做delay（比如
其他应用需要用systick），则需在芯片驱动的头文件里修改devDelay宏定义为机器delay。

随后指定显存，指定完成后可用miniGUI库对显存进行操作,显存内容操作完毕后，
先调用EPD_init初始化墨水屏，随后再调用发送函数将显存数据发送给墨水屏,
再调用update显示，最后调用sleep睡眠。

每次从掉电或者睡眠唤醒都需调用EPD_Init初始化。

局刷：刚上电不能局刷，局刷之间不能断电，芯片需要保持RAM内的内容来记忆屏幕已显示的内容并以此决定局刷波形。
调用局刷函数之前EPD应该先经过全刷初始化，并处于睡眠状态，否则RAM内容无法被正确配置。
对于这一款墨水屏连续局刷次数一般不超过十次。

正确做法是：全刷初始化-显示内容-睡眠-`EPD_PartialDisplay(imageCache)`-睡眠-`EPD_PartialDisplay(imageCache)`-睡眠...

## 显示函数
可用的函数详见minigui.c。画线，画方框位置可任意，快速填充无法接收x=0为输入，其他可任意。

快速写字符和写字符串可接受任意位置输入，但会和屏幕以8个像素为单位对齐，且无法指定颜色。普通写字符和写字符串可在任意位置。

快速画图只可接受宽度为128的图像数组（即取模之前图像宽度在121到128之间），因此只可指定y轴位置。
