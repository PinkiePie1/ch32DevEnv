# 蓝牙从机例程

官方的蓝牙从机例程，有五个

## 编译烧录
make -j999 flash

## 程序结构

以下列出自定义相关文件。

peripheral.c：可修改蓝牙广播参数和广播内容。
蓝牙广播的相关参数（广播间隔，连接间隔）在开头的宏定义里改

蓝牙设备名称在scanRspData里改，注意修改名称后数据长度，需要为名称长度+1，如第一个是0x0E,13+1
也可将设备名相关数据加入到主广播包中。
attDeviceName也是设备名，但只有在配对之后才会被主机读取，一般会保持这两个一致，但并非强制标准，也不影响程序运行。

如希望设备在某些事件时做出额外响应，应在对应的回调函数（CB）里增加代码。比如若希望连接上之后亮灯，就应将亮灯代码写在Peripheral_LinkEstablished函数中。这些函数在启动时被注册到蓝牙协议栈中，并由协议栈在对应时机调用。注意这些代码不应阻塞过长时间，如时间过长可拆开写成TMOS事件。

gattprofile.c：可修改gatt服务器的相关内容，比如增加，减少或者改变特性。
根据里面的代码依葫芦画瓢进行修改即可，注意如果改变了读写权限，还需在对应的回调函数里实现读写功能。
如果希望单片机对数据写入或者读出作出反应（亮灯，显示写入数据等），也可写在相应的回调函数中.
例如，如果希望单片机在characteristic1被写入某个值时执行操作，应该在simpleProfile_WriteAttrCB这个函数中增加相关代码（例如设置TMOS事件亮灯）
